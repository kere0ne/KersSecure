# KersSecure

Responsive static landing page for KersSecure.

## Deploy with GitHub Pages
1. Open the repository Settings.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. GitHub will publish the site at https://kere0ne.github.io/KersSecure/.

## Scope
This is a frontend preview only. Authentication, cloud storage, AI features, billing, and team collaboration require backend implementation and provider credentials. KersSecure is positioned for authorized game development and QA, not anti-cheat bypass or cheating.
